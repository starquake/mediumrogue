mediumrogue — terrain atmosphere: six passes over the same patch

Same seed, same hexes, same palette every panel (grass #35513a · forest #22391f · water #1d3d5c · rock #45443f) — only the treatment changes. Cost notes assume the deployed world: 43,561 hexes baked into one Graphics batch, and a client that has to survive CI's software renderer. Panels are ordered cheapest first.

A · Today — flat fill + per-hex outline

The baseline. Every hex of a type is the exact same colour, so terrain reads as a quilt of cells rather than as land. The outline on every hex is doing a lot of the visual work.

B · Per-hex value noise — one line of maths

Deterministic brightness jitter per hex, hashed from its own q,r. Regions immediately read as surfaces. Cost: zero — same one batch, just a different fill colour per hex.

C · Borders only — outline where terrain changes

Noise, plus the outline drawn only where two different terrains meet. Forests and coasts become masses with a shoreline instead of a grid. Cost: negative — strictly fewer strokes than today.

D · Grain texture — per-terrain pattern fill

A small tiling grain per terrain: speckle on grass, coarse mottle on forest, fracture lines on rock, banding on water. Cost: 4 small textures, one extra bind per terrain; still batched.

E · Scatter details — sparse motifs

Deterministic tufts on forest and flecks on rock, seeded per hex so they never shimmer. Cost: real — extra geometry per hex, but only ever inside the 20-hex interest radius.

F · Everything — B + C + D + E, plus a warm/cool tilt

All four, plus a very slight warm→cool gradient across the world so a screenful is never one flat hue. This is the "atmospheric" end of the dial.
